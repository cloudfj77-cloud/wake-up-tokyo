## 4. 原生实现约束

- 先读 `skills/forgeax-engine-sdk/references/api-index.md`；按任务读取安装在本项目的相关技能短入口。查命令用 `pnpm exec forgeax help <path> --json`，不凭记忆编参数。
- `forge.json#roots` 是唯一插件装配入口，沿用稳定 GUID；不另建渲染循环、平行生命周期或引擎装配清单。
- 持久资源走 source → importer/cooker → catalog → `assets.load(guid, kind)`。只编辑资源源文件与允许的 authoring sidecar，不手改 DDC、生成目录、pack-index 或 dist。
- 运行中生成内容使用官方运行时资产 API，并正确释放。玩法由 World/ECS/原生插件持有；DOM、Web Audio 和浏览器 API 放 Frontend；清理归属 `ctx.effect()`。
- 引擎导入只用 `@forgeax/engine` 及公开 facade，不导入物理 `@forgeax/engine-*` 包。加依赖用包管理器，避免不必要的框架和依赖。
- 当前 pnpm 方案使用普通 JavaScript pnpm 12.15.0；旧 standalone pnpm 曾触发锁文件不一致，见 feedback。先检查实际环境，不能通过手改 SDK、staging 或锁文件伪装通过。
- 对齐既有材质参数契约。已有导入材质与手写材质曾出现 `material-artifact-conflict / param-schema`；不要悄悄删材质、关闭校验或替换成白模绕过。
- 发现黑屏、缺物体、异常明暗或闪烁且原因不明，按项目 RHI Debug 流程先取诊断证据；不要反复猜 shader 参数。
- 读取原游戏资源时只复制到样板，保留来源、哈希、署名和修改记录。不能修改原资产来迁就导入器。
- 存档、设置和调试数据使用样板独立的键空间与版本；不得覆盖原游戏进度，不能为比较清除用户浏览器全部数据。

## 5. 必须保留的产品要求

完整核对表在 ACCEPTANCE.md。核心要求包括：

- 中文标题统一《Wake up 打工人！》；完整游戏最终默认海滨地图，咖啡店只是首个迁移切片。
- WASD 移动、E 奔跑、空格翻滚、Shift 跳跃；移动中一次按键即可翻滚，新动作能立即切换，不重新引入恢复僵直或双按触发。
- 注射器在玩家视角下可辨认，肩扛、紫色液体可见、开火抬枪回弹；三次有效命中蓄满，下一发强化。
- 敌方红血条、友方和玩家绿血条，清晰稳定；感染转阵营有过渡。
- 原版已验收的喷汁、留痕、感染音画、六尖累积标、侧边感染记录等逐项还原，不用简单计数变化代替反馈。

这些要求不等于每个阶段都要一次做完。严格按阶段划分交付；遇到与原版现状不一致，以用户最新明确要求优先，并把差异列出来。

- 最终代码必须通过官方 owner 浏览器的 `project play` 或 `dev verify`。用真实输入，读取游戏投影断言，查看截图并确认可见变化；刷新后再次进入。构建成功、HTTP 200、静态图片或单位测试不能单独算通过。
