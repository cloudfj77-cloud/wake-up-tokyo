## 性能窗口

同一台桌面机器实际完成的渲染帧，10 秒普通咖啡店窗口：Play 26 为 600 帧 / 10,000.605ms = 59.996 FPS；Play 31 为 596 帧 / 10,000.445ms = 59.597 FPS。

这些数字不代表全程、密集战斗、物理手机或比 Three.js 更快。手机操作证据来自 Chrome 真实 CDP 触屏事件与 844×390 / 390×844 视口，未测物理手机。早期 M1 局部样板的 60.1 FPS 不用于本版比较。脚本推进时间时的页脚 FPS 也不作为实测帧率。

## 画面与实现差异

- 使用原模型/贴图/动作和原版 LUT；原生 Standard 光照仍与旧 Three.js 的漫画黑描边/法线后处理不同，当前不是逐像素复刻。
- 原资源复制件经过稳定命名、重复几何清理、无效顶点色约束、缺失 UV/静止动画通道补齐。贴图最大 1024，无压缩导入以避开首次大图切换的帧看门狗；原文件保留。
- 声音使用原音频样本；脚步和反馈已接入，空间环境混音与旧游戏仍有差异。
- 原游戏和天工版使用各自独立存档格式；不直接覆盖原存档。
