# 天工迁移样板范围

基准：原仓库 PR33 合并提交 e2436475c5d52c5ecb0012260fab52405cffdf71（v0.3.76）。只在本独立工程内制作迁移试验，原游戏和旧兼容工程保留。

官方 game-3d 模板处置：保留原生 Engine/Frontend 根插件装配、ECS 调度、资源导入与真实浏览器验证路径；替换幻想展台、花瓶编辑器、模板 HUD 和场景摆放为地铁出口与咖啡店实景切片。角色和碰撞按实际移植结果记录，不将模板角色冒充原版角色。无关能力保持关闭。样板内无关模板源文件已清理，验收使用新玩法测试；原游戏和旧兼容工程未改。

需要 → 原生能力 → 证据：真实场景和模型 → GUID 导入／资源目录 → 资源验证、像素截图；输入和跳滚／感染 → World 资源和 ECS 系统 → 单元检查与真实按键游玩；HUD → Frontend 根 → 截图和拾取／充能提示；渲染性能 → 同资源同场景配对窗口 → 实际完成帧采样、设备和视口记录。

局限：这是局部迁移样板，不替换正式游戏，不承诺整个游戏帧率，不构建手机或 Windows 安装包。
