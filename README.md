# 都给我醒过来！ / WAKE UP TOKYO

当前版本以 `package.json` 和游戏主菜单为准。本次验收节点为 **Demo v0.2.1**，更新记录见 [CHANGELOG.md](CHANGELOG.md)，后续编号规则见 [VERSIONING.md](VERSIONING.md)。

桌面键鼠第三人称体素感染游戏。统一设计依据见 DESIGN.md。能力树按飞书《（2）玩家相关系统》落地：九种三级变异，人物整体移速已下调。

## 启动

npm install
npm run dev

本地地址 http://127.0.0.1:5200/ 。npm test 执行规则与模型测试；npm run build 生成生产版本。

不想开终端的话，双击仓库根目录的 `启动游戏-Mac.command`（Windows 用 `启动游戏-Windows.bat`），脚本会装依赖、起本机服务并自动打开浏览器。缺 Node.js 时会提示去 nodejs.org 安装。

## 操作

WASD 移动；鼠标锁定后转向，未锁定时右键拖动转向；空格跳跃；**Shift 翻滚**；C 蹲伏；**1 徒手，2 起按获得顺序切换枪械或感染发射器**；**左键 / J 轻击**；**右键 / K 重击**；E 装填；R 号令召集；Esc / P 暂停；**F3 打开警戒 / 动态难度调参台**（也可 `?debug=1`）。

升级先显示「升级！」，约一秒后淡入三张能力卡。**点击能力卡即可获得能力并继续战斗，无需二次确认**；每张卡本级可单独刷新一次，刷新不会领取能力，连续点击也只领取一次。开局可选一次，后续升级约三秒后自动选卡，Tab 可提前打开。选卡时战场暂停。九种能力：空气传播、枪？枪！、可感染发射器、狂杀、持续感染、急速、皮糙肉厚、生存与进化、听我号令。

警戒随等级和有效战斗时间增长：`20 × (等级 - 1) + 0.1 × 战斗秒数`。警戒达到 500 后开始三分钟镇压倒计时，同时出现三座削弱设施。设施可做可不做，完成会削弱 Boss 的护盾、强化或增援；倒计时归零时 Boss 登场。

击败 Boss 后可以继续自由活动，再点击「结束本局」或从暂停菜单结束，均保留胜利结果。Boss 战退出后继续游戏会从入场检查点重试。当前存档格式为 10，格式 9 的旧进度不兼容；Demo v0.2.0 与 v0.2.1 之间可以续玩。


## 实现

- rules.js：独立感染、伤害、升级、任务、胜负规则。
- characters.js：用户GLB骨骼克隆、职业配饰、阵营色和动作。
- syringe.js：程序化巨型紫液注射枪、透明液罐、发光针头。
- boss.js：基于参考角色轮廓的程序化体素巨像。
- world.js：东京十字路口、体素立面分块与可破坏设施。
- music.js：原创程序合成电子音乐和音效。
- main.js：输入、AI、弹道、镜头、存档与界面。

## 验证与范围

`npm test` 当前执行 59 项游戏测试，包括 Boss 续玩、增援投放、胜利结算及鼠标捕获回归检查。ForgeaX 适配工程另有 7 项版本管理测试。验收覆盖开局、单击选卡、独立刷新、连续点击防重复、暂停、Boss 入场与续玩；Boss 节奏按本版规则保留。

本仓库保留团队原有的根目录源码结构，生产构建输出到 `dist/`。本地 ForgeaX 工程使用相同的游戏源码，放在其 `source/` 中，构建输出到 `web/`；启动适配和输出路径各自保留。不要把整个 ForgeaX 工程直接覆盖到本仓库根目录。

本版是可玩 Demo：建筑为分块破坏和简化坍塌，NPC 采用简单避障，职业装束和黄色 Boss 为程序化体素重建，不是最终手工精修美术。Boss 已实现阶段承伤、追击、嘴部黄色炮弹和核心过热窗口，复杂扫射、分离装甲节点仍待后续精修。存档仅保存本机街区进度；Boss 战从进场前存档重试。

仅开发环境提供 ?test=boss 用于直接验证Boss，生产构建会移除测试入口。

## Playtest 04：日式河畔体素城市

新地图替换原程序化街区，保留河道、两座桥、113 栋建筑、东京塔、摩天轮、樱花、交通与沿岸街道。

- Blender 原始工程与原说明：`art/scenes/`（原文件完整复制，未修改）。
- 浏览器资源：`assets/scenes/riverside.glb`，Draco 压缩、顶点色材质；解码器随站点提供。
- 地形与静态碰撞：`assets/scenes/terrain.json`，0.5 米采样；包含河岸、桥面、车辆和护栏。
- 地图加载与任务布置：`riverside-world.js`；人物、倒计时期间的削弱设施和巨像出生点落在可行走位置。跨河 AI 经桥梁寻路。
- 导出脚本：`scripts/export_scene.py`。用 Blender 后台模式打开 `art/scenes/日式河畔城市_体素版.blend`，再通过 `--python` 执行此脚本重新导出。
- 原场景静态行人由现有可感染角色替代。新地图独立存档，避免旧街区坐标错位。

限制：Cycles 程序材质转换为近似顶点色，浏览器光照与 Blender 渲染不完全一致。建筑仍按整体生命值破坏并产生方块粒子；河道、桥梁和地标保留为静态结构，没有完整体素逐块破坏和刚体坍塌物理。地形为采样碰撞，角色不支持游泳或进入建筑内部。
