# 都给我醒过来！ / WAKE UP TOKYO

当前版本以 `package.json` 和游戏主菜单为准。当前开发版本为 **Demo v0.3.0**（企微设计对齐，待试玩验收）；上一团队同步节点为 Demo v0.2.3，更新记录见 [CHANGELOG.md](CHANGELOG.md)，后续编号规则见 [VERSIONING.md](VERSIONING.md)。

桌面键鼠第三人称体素感染游戏。能力设计依据为用户提供的漫画技能包；补兵、掉落等系统沿用企业微信「代号：Wake Up」的详细配置，已核实范围与适配值见 [企微设计对齐说明](docs/wecom-design-alignment.md)。DESIGN.md 保留历史方案。能力树以用户提供的漫画技能包为准：八种三级变异，人物整体移速已下调。

## 启动

npm install
npm run dev

本地地址 http://127.0.0.1:5200/ 。npm test 执行规则与模型测试；npm run build 生成生产版本。

npm run build:single 会额外产出一个可离线双击运行的单文件 HTML（release/wake-up-tokyo.html，约 200MB）。模型、贴图、Mixamo 角色资源与 Draco 解码器全部以 data URI 内联；运行时由注入的拦截器把 fetch / XHR / img.src 指向相对路径的请求改写成内联资源，因此 file:// 下无需任何服务。每帧都需要重新构建，改动代码后要重跑一次。

不想开终端的话，双击仓库根目录的 `启动游戏-Mac.command`（Windows 用 `启动游戏-Windows.bat`），脚本会装依赖、起本机服务并自动打开浏览器。缺 Node.js 时会提示去 nodejs.org 安装。

## 不想装环境的本地版

`npm run local` = `vite build` + `node scripts/serve.mjs 5310 dist`，构建完直接在 http://127.0.0.1:5310/ 起服务。`scripts/serve.mjs` 只依赖 Node 内置模块，不需要 `npm install`，也不联网，只监听 127.0.0.1。

分发给同学时用 `scripts/launch-mac.command`：把它和 `dist/` 的产物放进同一个文件夹，双击即可（脚本会依次找 PATH 里的 node、常见安装位置、WorkBuddy 托管版本，都没有时退回 `python3 -m http.server`）。这条路径**比 200MB 单文件可靠得多**——实测构建产物 148MB 的本地版 1.9 秒进入可点击，而单文件要塞进 206MB 的 HTML，Chrome 能扛、Safari 基本打不开。

## 操作

WASD 移动；进入游戏后鼠标隐藏并转向，Esc 暂停后显示鼠标，未锁定时右键拖动转向；空格跳跃；**Shift 短按闪避、长按奔跑**（奔跑消耗耐力）；C 蹲伏；**1 徒手，2 起按获得顺序切换武器，也可用滚轮循环切换**；**左键 / J 轻击**；**右键 / K 重击**；**R 装填**；解锁「听我号令」后 F 召集 / 解散；**Tab 打开/关闭城市地图，Esc 关闭地图或暂停**；F3 调参。

开局可选一次能力，升级后自动弹出选卡并暂停战场。点击能力卡立即获得；每张卡本轮可刷新一次。基础等级上限 **15**，生存与进化三级提高到 **50**，16 级起不发升级抽取次数。注射器普通弹一级感染/伤害为 **12/4**，二级及三级为 **20/8**，三级强化弹为 **45/12**。

地图有血包（回复最大生命 30%，满血不消耗）、狂暴因子（本级需求 10% 经验）、狂暴药水（临时攻击/感染/移速增益）。市民沿固定路线往返或定点停留，不再因玩家累计感染而逃离。

调度按玩家等级、转化友军阶级计算权重，排除召唤护卫；单波预算不超过目标权重 25%，已存在与排队敌军均扣预算。耗材按区域库存每 10 秒检查，阶段 3 起补基础持棍巡警。

警戒随累计经验和有效战斗时间增长：`累计经验 / 3 + 0.1 × 战斗秒数`，阶段阈值为 10 / 100 / 300 / 500。警戒达到 500 后开始两分钟镇压倒计时，同时出现三座削弱设施。设施可做可不做，完成会削弱 Boss 的护盾、强化或增援；倒计时归零时 Boss 登场。

击败 Boss 后可以继续自由活动，再点击「结束本局」或从暂停菜单结束，均保留胜利结果。Boss 战退出后继续游戏会从入场检查点重试。当前存档格式为 11，可读取格式 10；旧档超出基础上限的等级会收敛到 15（已解锁进化三级则上限 50），已拥有的能力与累计警戒经验保留。格式 9 不兼容。


## 实现

- rules.js：独立感染、伤害、升级、任务、胜负规则。
- characters.js：用户GLB骨骼克隆、职业配饰、阵营色和动作。
- syringe.js：程序化巨型紫液注射枪、透明液罐、发光针头。
- boss.js：基于参考角色轮廓的程序化体素巨像。
- world.js：东京十字路口、体素立面分块与可破坏设施。
- music.js：原创程序合成电子音乐和音效。
- main.js：输入、AI、弹道、镜头、存档与界面。

## 验证与范围

`npm test` 包含企微设计对齐回归测试及原有游戏测试，覆盖三次有效命中、霰弹与穿透去重、空弹匣保留充能、旧存档、能力顺序与动作衔接，以及原有 Boss 和鼠标捕获回归。ForgeaX 适配工程另有 7 项版本管理测试。已在 Chrome 验证单卡刷新、准星居中、连滚、滚接跳、落地接滚及暂停捕获。用户已试玩验收；ForgeaX 此前报告的严重卡顿尚未作为本轮修复验收。

本仓库保留团队原有的根目录源码结构，生产构建输出到 `dist/`。本地 ForgeaX 工程使用相同的游戏源码，放在其 `source/` 中，构建输出到 `web/`；启动适配和输出路径各自保留。不要把整个 ForgeaX 工程直接覆盖到本仓库根目录。

本版是可玩 Demo：建筑为分块破坏和简化坍塌，NPC 采用简单避障，职业装束和黄色 Boss 为程序化体素重建，不是最终手工精修美术。Boss 已实现阶段承伤、追击、嘴部黄色炮弹和核心过热窗口，复杂扫射、分离装甲节点仍待后续精修。存档仅保存本机街区进度；Boss 战从进场前存档重试。

仅开发环境提供 ?test=boss 用于直接验证Boss，生产构建会移除测试入口。

## 薪火能力

新增第九种三级能力「薪火」，可从升级卡获得。范围内友方觉醒者战斗阵亡时加层并刷新持续时间，满层仍刷新。一级为 18 米 / 3 层 / 8 秒 / 每层伤害及感染值 +6%；二级为 24 米 / 5 层 / 12 秒 / 每层 +8%；三级每层 +10%，已满层后再次阵亡会释放 24 米紫色火焰脉冲，范围内敌人增加基础 1 点感染值（享受薪火加成，满层为 1.5 点）。自身与范围内友方觉醒者均受伤害及感染值增益，HUD 显示层数与剩余时间。

### 小队增援（v0.3.35）

增援按 2～3 人步兵小队、单辆装甲分批进入，组内默认间隔 0.18 秒，组间 0.8～1.5 秒，每三组额外停顿 0.6 秒。普通压力检查间隔 3～5 秒，未削弱的 Boss 增援为 2～4 秒，待生成单位计入难度预算；队列最多 18 人，活跃敌方地面单位最多 96 个。每帧最多生成一人、创建两个人物模型。正面进场从 56～74 米的区域随机选点，侧后方从 22～42 米随机选点；同一小队成员在附近随机散开；地形修正后再次检查视野，找不到隐藏点就延迟重试。小队向投放时锁定的玩家区域赶路 6 秒，途中攻击射程内目标、冷却期间继续赶路，然后恢复正常 AI。盾冲距离从 6.5 米缩短到 3.2 米，发动距离由 7 米缩短到 4.3 米。
