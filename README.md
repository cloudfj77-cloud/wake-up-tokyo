# Wake up 打工人！ / WAKE UP TOKYO

Android 手机试玩版：左侧摇杆＋右侧战斗按键，支持横屏离线安装。安装、构建和验证说明见 [Android 手机试玩版](docs/android-mobile.md)。

整合试玩版默认进入东京立体街区；菜单可切换海滨钟楼广场，也可通过 `?map=riverside` 直接进入东京。两张地图继续使用各自的存档。

当前版本以 `package.json` 和游戏主菜单为准。本批试玩版本为 **Demo v0.3.61**，包含 PR29、PR30 的隐私页面、性能优化及验收修复；更新记录见 [CHANGELOG.md](CHANGELOG.md)，编号规则见 [VERSIONING.md](VERSIONING.md)。

支持桌面键鼠和手机触屏的第三人称体素感染游戏。Windows EXE、HTML 资源包和 APK 的构建步骤见 [双端构建说明](docs/android-mobile.md)。能力设计依据为用户提供的漫画技能包；补兵、掉落等系统沿用企业微信「代号：Wake Up」的详细配置，已核实范围与适配值见 [企微设计对齐说明](docs/wecom-design-alignment.md)。DESIGN.md 保留历史方案。能力树以用户提供的漫画技能包为准：八种三级变异，人物整体移速已下调。

## 启动

npm install
npm run dev

本地地址 http://127.0.0.1:5200/ 。npm test 执行规则与模型测试；npm run build 生成生产版本。

音乐、音效、环境和固定电台现已接入 Wwise，完整声音版使用 `npm run local`，交付使用 `npm run package:local`；设计、工程和验证说明见 [Wwise 声音工程](audio/wwise/README.md)。

npm run build:single 会额外产出一个单文件视觉预览（release/wake-up-tokyo.html），直接双击时不支持 Wwise 音乐。模型、贴图、Mixamo 角色资源与 Draco 解码器全部以 data URI 内联；运行时由注入的拦截器把 fetch / XHR / img.src 指向相对路径的请求改写成内联资源，因此 file:// 下无需任何服务。每帧都需要重新构建，改动代码后要重跑一次。

不想开终端的话，双击仓库根目录的 `启动游戏-Mac.command`（Windows 用 `启动游戏-Windows.bat`），脚本会装依赖、起本机服务并自动打开浏览器。缺 Node.js 时会提示去 nodejs.org 安装。

## 不想装环境的本地版

`npm run local` = `vite build` + `node scripts/serve.mjs 5310 dist`，构建完直接在 http://127.0.0.1:5310/ 起服务。`scripts/serve.mjs` 只依赖 Node 内置模块，不需要 `npm install`，也不联网，只监听 127.0.0.1。

分发使用 `npm run package:local` 生成的完整文件夹。Mac 双击其中的启动器，使用 Node.js，缺少时退回 Python3；Windows 使用 Node.js 和对应 bat。收件人无需安装开发依赖或 Wwise。

2026-10-19 的精选声音版包含 **193 个音效媒体 + 7 个音乐媒体 = 200 个**，保留全部 91 类声音。清理重复音乐并无损压缩后，本地交付文件从 221.4 MiB 降至 **89.8 MiB**，减少 **59.4%**，逐文件校验压缩前后 SHA-256。压缩包须使用随附服务器和启动器；普通 `dist/` 保持标准资源格式，供静态部署使用。完整记录见 [包体优化数据](audio/wwise/package-optimization.json)。长音乐和环境现使用 Wwise 分段流式读取，常驻银行为 2.85 MiB，另设 2 MiB I/O 缓冲；总音频交付文件约 11.03 MiB。

长时间播放增加了分段读取超时/重试、绕过 HTTP 区间缓存及循环音乐自动恢复。遇到断音可在 `?audio=1` 下载当前音频诊断；暂停和结局短句不会被自动重播。

角色加载同时启动独立任务，优先使用现有替换模型，仅在失败时加载对应备用模型；正常启动跳过原先额外下载的 22.3 MiB 主角 GLB。警察共享贴图，重复动画文件只解析一次。模型与贴图保留原资源；音乐与主要战斗音效保持原 Vorbis Q4，环境和电台使用独立压缩档位，听感待验收。尚未量化帧率和峰值内存收益。

## 操作

WASD 移动；进入游戏后鼠标隐藏并转向，Esc 暂停后显示鼠标，未锁定时右键拖动转向；空格跳跃；**Shift 短按闪避、长按奔跑**（奔跑消耗耐力）；C 蹲伏；**1 徒手，2 起按获得顺序切换武器，也可用滚轮循环切换**；**左键 / J 轻击**；**右键 / K 重击**；**R 装填**；解锁「听我号令」后 F 召集 / 解散；**Tab 打开/关闭城市地图，Esc 关闭地图或暂停**；F3 调参。

开局可选一次能力，升级后自动弹出选卡并暂停战场。点击能力卡立即获得；每张卡本轮可刷新一次。基础等级上限 **15**，生存与进化三级提高到 **50**，16 级起不发升级抽取次数。注射器普通弹一级感染/伤害为 **12/4**，二级及三级为 **20/8**，三级强化弹为 **45/12**。

地图有血包（回复最大生命 30%，满血不消耗）、狂暴因子（本级需求 10% 经验）、狂暴药水（临时攻击/感染/移速增益）。市民沿固定路线往返或定点停留，不再因玩家累计感染而逃离。

调度按玩家等级、转化友军阶级计算权重，排除召唤护卫；单波预算不超过目标权重 25%，已存在与排队敌军均扣预算。耗材按区域库存每 10 秒检查，阶段 3 起补基础持棍巡警。

警戒随累计经验和有效战斗时间增长：`累计经验 / 3 + 0.1 × 战斗秒数`，阶段阈值为 10 / 100 / 300 / 500。警戒达到 500 后开始两分钟镇压倒计时，同时出现三座削弱设施。设施可做可不做，完成会削弱 Boss 的护盾、强化或增援；倒计时归零时 Boss 登场。

击败 Boss 后可以继续自由活动，再点击「结束本局」或从暂停菜单结束，均保留胜利结果。Boss 战退出后继续游戏会从入场检查点重试。当前存档格式为 11，可读取格式 10；旧档超出基础上限的等级会收敛到 15（已解锁进化三级则上限 50），已拥有的能力与累计警戒经验保留。格式 9 不兼容。


## 实现

- rules.js：独立感染、伤害、升级、任务、胜负规则。
- characters.js：用户GLB骨骼克隆、职业配饰、阵营色和动作。
- syringe.js：程序化巨型紫液注射枪、透明液罐、发光针头。
- boss.js：基于参考角色轮廓的程序化体素巨像。
- world.js：东京十字路口、体素立面分块与可破坏设施。
- music.js：共用 Wwise 引擎的音乐、音效、环境与电台接入。
- music-director.mjs：音乐状态、初始化和混音意图。
- main.js：输入、AI、弹道、镜头、存档与界面。

增援按 2～3 人步兵小队、单辆装甲分批进入，组内默认间隔 0.18 秒，组间 0.8～1.5 秒，每三组额外停顿 0.6 秒。普通压力检查间隔 3～5 秒，未削弱的 Boss 增援为 2～4 秒，待生成单位计入难度预算；队列最多 18 人，活跃敌方地面单位最多 96 个。每帧最多生成一人、创建两个人物模型。正面进场从 56～74 米的区域随机选点，侧后方从 22～42 米随机选点；同一小队成员在附近随机散开；地形修正后再次检查视野，找不到隐藏点就延迟重试。小队向投放时锁定的玩家区域赶路 6 秒，途中攻击射程内目标、冷却期间继续赶路，然后恢复正常 AI。盾冲距离从 6.5 米缩短到 3.2 米，发动距离由 7 米缩短到 4.3 米。
