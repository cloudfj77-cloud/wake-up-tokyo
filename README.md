# 都给我醒过来！ / WAKE UP TOKYO

当前版本以 `package.json` 和游戏主菜单为准。当前待试玩版本为 **Demo v0.2.6**；上一团队验收节点为 Demo v0.2.5，更新记录见 [CHANGELOG.md](CHANGELOG.md)，后续编号规则见 [VERSIONING.md](VERSIONING.md)。

桌面键鼠第三人称体素感染游戏。统一设计依据见 DESIGN.md。能力树按飞书《（2）玩家相关系统》落地：九种三级变异，人物整体移速已下调。

## 启动

npm install
npm run dev

本地地址 http://127.0.0.1:5200/ 。npm test 执行规则与模型测试；npm run build 生成生产版本。

npm run build:single 会额外产出一个可离线双击运行的单文件 HTML（release/wake-up-tokyo.html，约 200MB）。模型、贴图、Mixamo 角色资源与 Draco 解码器全部以 data URI 内联；运行时由注入的拦截器把 fetch / XHR / img.src 指向相对路径的请求改写成内联资源，因此 file:// 下无需任何服务。改动代码后需要重新构建。

不想开终端的话，双击仓库根目录的 `启动游戏-Mac.command`（Windows 用 `启动游戏-Windows.bat`），脚本会装依赖、起本机服务并自动打开浏览器。缺 Node.js 时会提示去 nodejs.org 安装。

## 不想装环境的本地版

`npm run local` = `vite build` + `node scripts/serve.mjs 5310 dist`，构建完直接在 http://127.0.0.1:5310/ 起服务。`scripts/serve.mjs` 只依赖 Node 内置模块，不需要 `npm install`，也不联网，只监听 127.0.0.1。

Mac 分发时，先构建，再把两个启动文件一起复制到构建目录：

```sh
npm run build
cp scripts/launch-mac.command scripts/serve.mjs dist/
```

把整个 `dist/` 文件夹交给同学，保留 `index.html`、assets、音乐与角色资源等文件，双击其中的 `launch-mac.command` 即可。启动器有执行权限，会依次寻找 Node.js；没有 Node.js 时尝试 Python 3。源码仓库也可以在构建完成后直接双击 `scripts/launch-mac.command`。服务只监听本机 127.0.0.1。未安装 Node.js 和 Python 3 的电脑仍需先安装其中一种运行环境。

## 操作

WASD 移动；鼠标锁定后转向，未锁定时右键拖动转向；空格跳跃；**Shift 翻滚**；C 蹲伏；**1 徒手，2 起按获得顺序切换枪械或感染发射器**；**左键 / J 轻击**；**右键 / K 重击**；E 装填；R 号令召集；Esc / P 暂停；**F3 打开警戒 / 动态难度调参台**（也可 `?debug=1`）。

升级先显示「升级！」，约一秒后淡入三张能力卡。**点击能力卡即可获得能力并继续战斗，无需二次确认**；每张卡本级可单独刷新一次，刷新不会领取能力，连续点击也只领取一次。开局可选一次，后续升级约三秒后自动选卡，Tab 可提前打开。选卡时战场暂停。九种能力：空气传播、枪？枪！、可感染发射器、狂杀、持续感染、急速、皮糙肉厚、生存与进化、听我号令。

警戒随累计经验和有效战斗时间增长：`累计经验 / 3 + 0.1 × 战斗秒数`，阶段阈值为 10 / 100 / 300 / 500。警戒达到 500 后开始两分钟镇压倒计时，同时出现三座削弱设施。设施可做可不做，完成会削弱 Boss 的护盾、强化或增援；倒计时归零时 Boss 登场。

击败 Boss 后可以继续自由活动，再点击「结束本局」或从暂停菜单结束，均保留胜利结果。Boss 战退出后继续游戏会从入场检查点重试。当前存档格式为 10，格式 9 的旧进度不兼容；Demo v0.2.0 至 v0.2.6 之间可以续玩，旧存档的累计经验由等级和当前经验补算；v0.2.4 起原按发射次数累计的强化进度清零，新命中进度可正常保存。


## 实现

- rules.js：独立感染、伤害、升级、任务、胜负规则。
- characters.js：用户GLB骨骼克隆、职业配饰、阵营色和动作。
- syringe.js：程序化巨型紫液注射枪、透明液罐、发光针头。
- boss.js：基于参考角色轮廓的程序化体素巨像。
- world.js：东京十字路口、体素立面分块与可破坏设施。
- music.js：四首背景音乐的切换、循环与淡入淡出，以及带限幅的程序合成音效。
- main.js：输入、AI、弹道、镜头、存档与界面。

## 验证与范围

`npm test` 执行 103 项游戏与启动器测试，覆盖三次有效命中、霰弹与穿透去重、空弹匣保留充能、旧存档、能力顺序与动作衔接，以及原有 Boss 和鼠标捕获回归。ForgeaX 适配工程另有 7 项版本管理测试。已在 Chrome 验证单卡刷新、准星居中、连滚、滚接跳、落地接滚及暂停捕获。v0.2.5 已试玩验收，v0.2.6 待实机验收；ForgeaX 此前报告的严重卡顿尚未作为本轮修复验收。

本仓库保留团队原有的根目录源码结构，生产构建输出到 `dist/`。本地 ForgeaX 工程使用相同的游戏源码，放在其 `source/` 中，构建输出到 `web/`；启动适配和输出路径各自保留。不要把整个 ForgeaX 工程直接覆盖到本仓库根目录。

本版是可玩 Demo：建筑为分块破坏和简化坍塌，NPC 采用简单避障，职业装束和黄色 Boss 为程序化体素重建，不是最终手工精修美术。Boss 已实现阶段承伤、追击、嘴部黄色炮弹和核心过热窗口，复杂扫射、分离装甲节点仍待后续精修。存档仅保存本机街区进度；Boss 战从进场前存档重试。

仅开发环境提供 ?test=boss 用于直接验证Boss，生产构建会移除测试入口。

## Playtest 04：日式河畔体素城市

新地图替换原程序化街区，保留河道、两座桥、113 栋建筑、东京塔、摩天轮、樱花、交通与沿岸街道。

- 浏览器资源：`assets/scenes/riverside.glb`，Draco 压缩、顶点色材质；解码器随站点提供。
- 地形与静态碰撞：`assets/scenes/terrain.json`，0.5 米采样；包含河岸、桥面、车辆和护栏。
- 地图加载与任务布置：`riverside-world.js`；人物、倒计时期间的削弱设施和巨像出生点落在可行走位置。跨河 AI 经桥梁寻路。
