# 都给我醒过来！ / WAKE UP TOKYO · Playtest 04

桌面键鼠第三人称体素感染游戏。统一设计依据见 DESIGN.md。本分支按飞书《迭代记录》P0（节奏 / 难度）改过本地试玩：警戒与动态难度拆开，Shift 改为奔跑，并加入轻击 / 重击。

## 启动

npm install
npm run dev

本地地址 http://127.0.0.1:5200/ 。npm test 执行规则与模型测试；npm run build 生成生产版本。

## 操作

WASD 移动；鼠标锁定后转向，未锁定时右键拖动转向；空格跳跃；**Shift 按住奔跑**；C 蹲伏；1 徒手；2 注射枪；**左键 / J 轻击**；**右键 / K 重击**；E 装填；R 召集/解散最多六人；Esc / P 暂停；F3 或 `?debug=1` 打开调参台。

升级直接按 1/2/3 选择。开局一次，之后经验门槛递增、自动选择至少间隔 50 秒。Tab 可以主动使用待选次数。选择界面所有战场模拟暂停。

母体 100 生命。打工人两下轻击或一下重击即可转化。持枪单位先举枪，出射程后打完动作再追。城市警戒只随时间升档（90 秒 / 180 秒），升档只提示「敌方单位更强大了」。

任务推进到累计感染40人、摧毁3座中枢，并击败/转化高等级秩序单位后，巨大黄色体素Boss在中央路口降临。Boss 6000生命，重击前地面预警，重击后核心有额外承伤窗口。击败后完成“东京人觉醒”。

## 实现

- rules.js：独立感染、伤害、升级、任务、胜负规则。
- characters.js：用户GLB骨骼克隆、职业配饰、阵营色和动作。
- syringe.js：程序化巨型紫液注射枪、透明液罐、发光针头。
- boss.js：基于参考角色轮廓的程序化体素巨像。
- world.js：东京十字路口、体素立面分块与可破坏设施。
- music.js：原创程序合成电子音乐和音效。
- main.js：输入、AI、弹道、镜头、存档与界面。

## 验证与范围

14项测试覆盖两弹死亡、感染阈值、尸体和暂停、经验去重、净化反转、能力池、任务终局、Boss生命、模型骨骼及武器结构。浏览器检查开局、键盘选卡、换装、Boss外观和战斗。

本版是可玩Demo：建筑为分块破坏和简化坍塌，NPC采用简单避障，职业装束和黄色Boss为程序化体素重建，不是最终手工精修美术。Boss已实现阶段承伤、追击、预警重击和核心窗口，复杂扫射、分离装甲节点仍待后续精修。存档仅保存本机街区进度；Boss战从进场前存档重试。

仅开发环境提供 ?test=boss 用于直接验证Boss，生产构建会移除测试入口。

## Playtest 04：日式河畔体素城市

新地图替换原程序化街区，保留河道、两座桥、113 栋建筑、东京塔、摩天轮、樱花、交通与沿岸街道。

- Blender 原始工程与原说明：`art/scenes/`（原文件完整复制，未修改）。
- 浏览器资源：`assets/scenes/riverside.glb`，Draco 压缩、顶点色材质；解码器随站点提供。
- 地形与静态碰撞：`assets/scenes/terrain.json`，0.5 米采样；包含河岸、桥面、车辆和护栏。
- 地图加载与任务布置：`riverside-world.js`；人物、三座秩序中枢和巨像出生点落在可行走位置。跨河 AI 经桥梁寻路。
- 导出脚本：`scripts/export_scene.py`。用 Blender 后台模式打开 `art/scenes/日式河畔城市_体素版.blend`，再通过 `--python` 执行此脚本重新导出。
- 原场景静态行人由现有可感染角色替代。新地图独立存档，避免旧街区坐标错位。

限制：Cycles 程序材质转换为近似顶点色，浏览器光照与 Blender 渲染不完全一致。建筑仍按整体生命值破坏并产生方块粒子；河道、桥梁和地标保留为静态结构，没有完整体素逐块破坏和刚体坍塌物理。地形为采样碰撞，角色不支持游泳或进入建筑内部。
