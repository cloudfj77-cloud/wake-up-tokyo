# Demo v0.3.0：海滨钟楼广场

用户确认作为可选择的新地图加入。本仓库使用根目录游戏源码和 dist 构建输出；本地 ForgeaX 适配工程独立保留。

## 使用

启动游戏，在主菜单“觉醒区域”选择“海滨钟楼广场 · 新地图”，然后开始觉醒。原东京河畔仍为默认地图。链接参数 `?map=tidewater` 可直接选择广场；`?map=riverside` 选择原地图。

两张地图分别保存进度；旧河畔存档 key 与版本保持不变。新地图按原游戏流程选能力、感染市民、触发警戒、破坏削弱设施并迎战 Boss。

## 来源与实现

场景来自 jaydendavisnc/inkwave 的 Tidewater Plaza，锁定提交 `3e9b5505ea900cb41851b4d75f16d488552b1794`。只引入这张地图及共享场景依赖；MIT 版权声明、字体 OFL 与来源记录随源码和网页交付保留。

保留原程序化建筑、装饰、海面、纹理与日间光照，兼容 Wake Up 的 Three r180，不升级引擎。新地图按需加载。基于原碰撞盒构建可行走区域，排除海水、房顶和离岸装饰；台阶检查高度差，NPC 可绕钟楼到达另一侧。重布出生点、三座任务设施、增援点与 Boss，去掉新地图的河岸炮击限制。

## 范围

广场建筑为静态合批模型，尚未接入原地图的建筑挖洞/整体摧毁。三座削弱设施保持可破坏。现有移动系统每个 XZ 位置使用一个可行走高度，回廊重叠处使用上层平台，不能同时从上下两层穿行。

本次 PR 同步共享游戏源码，不包含 ForgeaX 工程外壳。浏览器测试记录见下方。
