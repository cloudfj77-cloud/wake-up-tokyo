# Demo v0.2.5：战斗 UI、强化炮与动作衔接

本次团队更新包含已验收的本地 v0.2.4 与 v0.2.5 内容，存档格式仍为 10。

## 玩家可见变化

- 单张能力刷新只播放该卡动效；点击卡片即可领取。
- 放大小地图，整理地图图例与任务说明，操作帮助放到右上角，移除底部中央的大块按键提示。
- 警戒升级时出现红色边缘与提示音，高警戒缓慢呼吸；暂停、选卡、胜利后隐藏，支持减少动态效果偏好。
- 准星点与圆环共用中心。三级注射器解锁后，枪械和注射器共享三环，每次有效命中积一环，三次后下一发强化炮。
- 一次扣扳机最多计一环；霰弹、穿透与 Boss 多帧碰撞不会重复积环，友军攻击和强化炮不充能。空弹匣保留充能，枪械强化炮消耗一发弹药。
- 能力按首次获得顺序从左到右连续排列，升级不改变位置。
- 按住 Shift 连滚，翻滚中按空格直接起跳；落地前 0.18 秒内按跳跃或翻滚可接下一动作。暂停、选卡或失焦清除缓冲输入。
- 翻滚动画与动作时长一致，连续滚动重启动画；空中射击不会反复重置跳跃动画。

## 验证

- 81 项游戏测试与生产构建通过，本地 ForgeaX 工程另有 7 项版本管理测试。
- 浏览器刷新中间卡后，另外两个卡片 DOM 不变，仅中间卡出现刷新动画。
- 实际弹道命中得到 0 → 1 → 2 → 3 环，下一发强化后归零；弹药消耗正确。
- 1920×1080、1280×720、800×600 下准星中心误差均为 0，主要 HUD 保持在窗口内。
- 约 2.3 秒连滚采样中衔接 3 次，没有采到中间动作归零的帧；滚接跳立即生效，落地第一帧可以接滚。
- 生产构建正常开局、单击选卡、能力顺序、真实鼠标捕获与暂停释放通过，浏览器无运行错误。
- 用户在 Chrome 试玩认可；本轮不包含 ForgeaX 卡顿问题的性能结论。

## 仓库结构

团队仓库继续使用根目录源码与 `dist/` 构建输出；ForgeaX 本地工程保留 `source/` 与 `web/`。共享游戏文件保持相同，两个工程的启动配置分别保留。
